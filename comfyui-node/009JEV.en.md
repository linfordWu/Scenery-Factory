# 009jev: Jev-guided native SLA

[简体中文](009JEV.md) · Experimental branch `exp/jev-adaptive-vsa`

**009jev is now a named, supported experimental method in this branch.** It retains the standard MiniMax H3 loader, linear layers and FastVAE, adding native SLA with per-layer keep rates selected by Jev from the first step. Node ID: `H3JevNativeSLAPatch`; display name: **009jev: Jev-guided Native SLA**. This is separate from the older W4A4/VSA path. It does not use FC1 W4A4 conversion, preconverted gates or VSA cube tiling. It is not integrated into main.

## Requirements

Generation was validated on Linux (aarch64), NVIDIA GB10, ComfyUI 0.36.0, commit `7a0b5eede3f9721c8faab290689893f36edc6d66`. The implementation uses internal APIs in `comfy_extras.nodes_sparse_attention`, native MiniMax H3's50 blocks and comfy-kitchen SLA. It supports **four steps and res_multistep**, not arbitrary models or samplers.

Examples use `minimax_h3_fused_refdelta_r1024_turbo8_mystic07_int8_convrot.safetensors`, a32B Qwen encoder, and H3 video/audio VAEs. See nodes127/128/119/120 for exact names. No weights are bundled or downloaded automatically.

Example workflows also require [KJNodes](https://github.com/kijai/ComfyUI-KJNodes) for ChunkFFN and [MotionCache-FastVAE](https://github.com/Mozer/ComfyUI-MiniMax-H3-MotionCache-FastVAE) for FastVAE. They do not use MotionCache output reuse.

## Install without weight conversion

Clone this branch into an existing isolated ComfyUI's `custom_nodes` directory. If this repository is already installed, update that copy rather than loading duplicate copies.

```bash
# Working directory: your ComfyUI/custom_nodes
git clone --branch exp/jev-adaptive-vsa --single-branch https://github.com/sepiablue-ai/ComfyUI-MiniMax-H3-W4A4-VSA.git
cd ComfyUI-MiniMax-H3-W4A4-VSA
python3 -m venv .venv-jev
.venv-jev/bin/pip install -r requirements-jev.txt
```

The SDK stays in its own venv. **For 009jev alone, do not run the W4A4 setup_env.py or convert.py:** those legacy tools require gates/conversion. Their distribution list includes the new modules, but their setup flow remains for W4A4.

Restart ComfyUI. Set the node's `sdk_python` to the dedicated venv's absolute Python path. An empty value uses ComfyUI's own Python, which must then have the SDK installed. Read the API key only from `TYPESAFE_API_KEY` inherited by the ComfyUI process. See the [secure environment-input example](JEV_ADAPTIVE.en.md). Never put the key in workflows, source code or shell history. Missing keys and invalid Python paths fail preflight.

Set `sdk_python` and submit once to an already running ComfyUI:

```bash
# Point node900's sdk_python at the dedicated venv and submit once
python3 - <<'PY'
import json, urllib.request
with open('examples/009jev_4step.api.json', encoding='utf-8') as f:
    graph = json.load(f)
graph['900']['inputs']['sdk_python'] = '/absolute/path/to/.venv-jev/bin/python'
req = urllib.request.Request(
    'http://127.0.0.1:8188/prompt',
    data=json.dumps({'prompt': graph}).encode('utf-8'),
    headers={'Content-Type': 'application/json; charset=utf-8'})
print(urllib.request.urlopen(req).read().decode('utf-8'))
PY
```

Use your server's port. Preserve the returned prompt ID and wait for completion before reading history. Do not resubmit because a response is uncertain.

When changing the prompt, update both node131's generation prompt and node900's `prompt_context`. Replace historical `initial_context` when its provenance no longer applies, or use the cold-start example. Never label historical statistics as current measurements. `prompt_context` overrides `initial_context.prompt`.

## What Jev controls

Jev selects **1/3/5/10% keep rates** per layer. SLA chooses the actual attention connections. The first call uses the prompt and optional historical statistics to decide all50 layers at once. Block0's initial choices are5/10%. This is a prior decision, not a preview of this run's output, and adds no probe forward.

Before steps2–4, the policy observes64 tokens by16 channels separately from actual audio/video rows: relative block residual, within-modality layer rank and cross-step residual change. Jev decides49 layers; block0 remains5%. **All50 transformer layers execute every step.** The illustration displays layers1–49 only.

Confidence below0.3 falls back to10% initially,5% later. API or answer-validation failure opens a circuit breaker: an initial failure retains10%, a later failure retains5%, with no subsequent calls. The model is `jev-1.13.0`, SDK timeout20s, retry0, at most4 calls for4steps. `fixed5`/`fixed10` fix **only the first step** and still make later API calls; normal009jev uses `jev_first`.

Audio queries and conditioning KV receive native SLA protection. Keep1% does not mean1% of total model computation. Standard SLA's internal statistics are used; old block outputs are not reused as an activation cache. No OCR or direct audio-quality score is supplied.

The API receives prompt text, supplied historical context and aggregated layer measurements. It does not receive raw images, audio or model weights. `[009jev]` logs contain decision state, answers and usage, including prompt contents. They exclude API keys and HTTP exception bodies.
