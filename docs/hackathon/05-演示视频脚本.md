# 演示视频脚本：短视频工厂 Agent

## 1. 演示目标

- 展示完整闭环：需求输入 → 结构化分镜 → 素材绑定 → 视频生成 → 质检 → 修复 / 审核 → 成片导出。
- 展示工程能力：状态机、事件流、任务恢复、证据链、测试和部署文档。
- 展示平台适配：Fusion Xpark GB10 Linux、NVIDIA Container Toolkit / CDI、ComfyUI、MiniMax-H3、Laya / OpenJev。
- 展示 StepFun：主 Agent 是首选配置，同时强调 provider 可插拔，不泄露密钥。

## 2. 推荐时长

| 段落 | 时长 | 内容 |
|---|---:|---|
| 开场 | 20 秒 | 一句话说明项目价值 |
| 痛点与方案 | 30 秒 | 从“生成一次”到“持续生产” |
| Web 工作台 | 40 秒 | 项目、素材、分镜、任务、审核界面 |
| StepFun 主 Agent | 40 秒 | 对话收集需求，生成结构化分镜 |
| Fusion Xpark GB10 本地生成 | 60 秒 | ComfyUI / MiniMax-H3 / Laya 加速 |
| 质检与修复 | 50 秒 | ScoreReport、证据、RepairPlan、人工审核 |
| 成片与追溯 | 30 秒 | 导出成片，回看输入与事件 |
| 总结 | 20 秒 | 回应评审标准 |

## 3. 分镜脚本

### 镜头 1：开场

画面：标题页 + Web 工作台首页。

口播：

> 这不是一个一次性视频生成 Demo，而是一套运行在 NVIDIA Fusion Xpark GB10 Linux 上的短视频工厂 Agent。它把 StepFun 主 Agent、多智能体协同、MiniMax-H3 本地生成、质检修复和成片导出放进同一条可追溯流水线。

### 镜头 2：行业痛点

画面：展示痛点页或 README 项目特点。

口播：

> 真实短视频生产的问题不是能不能生成，而是素材能不能复用、角色能不能一致、失败能不能解释、任务能不能恢复。我们把这些问题全部纳入生产系统。

### 镜头 3：Web 工作台

操作：打开项目列表、素材页、分镜页、任务页。

口播：

> Web 工作台是生产控制面。项目、素材、镜头、任务和审核共用同一份状态，每个步骤都有执行者、事件和产物。

### 镜头 4：StepFun 主 Agent

操作：进入对话出片，输入一个短剧需求，例如“30 秒竖屏雨夜悬疑短剧，3 个镜头，女主角发现一封旧信”。

口播：

> 主 Agent 首选配置为 StepFun 阶跃星辰。它负责把自然语言需求收敛为 brief、剧本、角色、场景和分镜。模型 provider 是可插拔的，密钥不进入仓库，也不会出现在演示画面中。

### 镜头 5：结构化分镜

操作：展示方案卡和每镜 ShotSpec：action、dialogue、duration、characters、motion_contract、beats、object_states、acceptance。

口播：

> 多智能体协同不是自由聊天，而是契约协作。编剧、选角、导演和提示词 Agent 都围绕同一个 ShotSpec 工作，代码负责时长、画幅、台词和密度约束。

### 镜头 6：Fusion Xpark GB10 本地生成

操作：启动生成，展示任务事件流和 ComfyUI 日志。

口播：

> 渲染由 Fusion Xpark GB10 上的 ComfyUI 和 MiniMax-H3 完成。009jev Native SLA 会从首步开始由本地 Laya 决策引擎选择逐层 keep rate。当前 5 秒 4 step 热缓存实测从 530.2 秒降到 340.1 秒。

### 镜头 7：质检与修复

操作：展示某个镜头的 ScoreReport、抽帧证据、失败标签和 RepairPlan；如果有可修复样本，执行一次修复。

口播：

> 质检不是一个总分，而是证据链。文件检查、抽帧评估、验收项和禁止项都会进入报告。修复 Agent 根据证据生成 RepairPlan，超过预算就进入人工审核。

### 镜头 8：成片与追溯

操作：导出成片，播放 3–5 秒；回到镜头详情，展示输入、参数、模型版本、事件和审核记录。

口播：

> 每个被交付的镜头都能回溯到输入、素材版本、工作流、seed、质检证据和审核记录。这是从 Demo 走向生产系统的关键。

### 镜头 9：总结

画面：评审标准对齐表。

口播：

> 这个项目用 Fusion Xpark GB10 本地算力承载完整短视频生产闭环，用 StepFun 主 Agent 和多智能体契约提升创作效率，用 Laya / OpenJev 和 009jev 降低无效生成，用 Agent Skills 把经验沉淀成可复用能力。

## 4. 演示前检查清单

- [ ] Fusion Xpark GB10 Linux 真实主机 `localhost` 已启动 ComfyUI 与 Scenery-Factory。
- [ ] ComfyUI 可通过 `http://localhost:8188` 访问，工作台可通过 `http://localhost:8600` 访问。
- [ ] `.env` 已配置 StepFun 主 Agent，或已准备备用 provider。
- [ ] 演示中不展示任何 API Key、完整 endpoint 密钥参数或私人素材。
- [ ] 预先准备一个已验收项目、一个待生成项目和一个可修复样本。
- [ ] 网络或外部服务异常时，切换本地 provider 继续演示。
- [ ] 视频画面中只展示变量名，例如 `SVF_CUSTOM_MODEL`，不展示密钥值。
